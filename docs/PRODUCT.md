# PRODUCT.md -- 产品描述

legal-knowledge-agent 项目产品描述:
-这是一个法律知识库与助手的agent,根据用户问题, 进行法律问题回答, 并且可以存储用户的问题与回答.

-用户可以在前端界面中上传文档, 作为知识库内容, 支持pdf, txt, md等格式. 上传后, 文档会被解析为向量, 并存储到向量数据库中
-用户可以在知识库管理页面(与对话历史同处侧边栏, 通过点击知识库管理按钮切换), 查看已上传的文档名称, 可以删除文档.
-用户可以在前端界面中创建新的对话, 并且可以在不同对话之间切换.
-用户可以在对话内容区域中输入用户问题, 并且可以流式显示模型回复.
-显示历史对话, 可以删除对话.
-前端界面设计风格与功能类似于codex网页版的界面设计, 审美高, 审美类似于苹果和Claude的界面设计, 交互简单
