# PRODUCT.md -- 产品描述

legal-knowledge-agent 项目产品描述:
-这是一个法律知识库与助手的agent,根据用户问题, 进行法律问题回答, 并且可以存储用户的问题与回答.

-用户可以在前端界面中上传文档, 作为知识库内容, 支持pdf, txt, md等格式. 上传后, 文档会被解析为向量, 并存储到向量数据库中
-用户可以通过侧边栏的「知识库」按钮切换到知识库管理视图(与对话历史同处侧边栏); 侧边栏仅显示文档数量与处理状态汇总, 不罗列文件名.
-已上传文档的名称、大小、处理状态与删除操作, 在主区域的知识库管理页查看和完成.
-用户可以在前端界面中创建新的对话, 并且可以在不同对话之间切换.
-点击「新对话」进入空白对话界面; 发送第一句提问时才真正创建会话, 并以该提问内容(截短)作为会话标题, 便于在历史列表中辨认(后端不会在提问后自动改标题).
-点击「新对话」时, 若当前处于知识库视图, 自动跳转回对话视图(新对话是对话行为, 不应停留在知识库页面).
-用户可以在对话内容区域中输入用户问题, 并且可以流式显示模型回复.
-当回答基于知识库检索(RAG)且检索有命中时, 回答完成后下方显示「参考文档」按钮, 点开后按序号展示参考的文档名称与对应命中内容; 参考来源随回答一起持久化, 刷新或重新打开会话后仍可查看.
-当回答未使用知识库检索或检索无命中时, 不显示「参考文档」按钮.
-显示历史对话, 可以删除对话.
-侧边栏历史对话按创建时间从上到下排列：最早创建的在最上面，新创建的会话追加到最下面.
-前端界面设计风格与功能类似于codex网页版的界面设计, 审美高, 审美类似于苹果和Claude的界面设计, 交互简单
