# PRODUCT.md -- 产品描述

本文件只描述**用户可见的产品行为与需求**（界面、交互、展示规则、边界）。
实现方式、分层结构、数据落点、Provider 切换、API 契约与测试体系等一律见 `docs/ARCHITECTURE.md`；
实现变更不得改变本文件描述的用户可见行为——**行为要变，先改本文件**。

## 1. 产品定位
- 法律知识库 + 法律问答助手 Agent：根据用户问题给出法律问题回答，并保存用户的问题与回答。

## 2. 知识库（文档）
- 用户可以在前端界面中上传文档作为知识库内容，支持 PDF、TXT、MD 等格式；上传后的文档会被解析并纳入知识库，供问答检索使用。
- 用户可以通过侧边栏的「知识库」按钮切换到知识库管理视图（与对话历史同处侧边栏）；侧边栏仅显示文档数量与处理状态汇总，不罗列文件名。
- 已上传文档的名称、大小、处理状态与删除操作，在主区域的知识库管理页查看和完成。
- 知识库文档列表按上传时间倒序展示：最新上传的文档排在最前面。

## 3. 对话
- 用户可以在前端界面中创建新的对话，并且可以在不同对话之间切换。
- 点击「新对话」进入空白对话界面；发送第一句提问时才真正创建会话，并以该提问内容（截短）作为会话标题，便于在历史列表中辨认（提问后标题不会再自动变化）。
- 点击「新对话」时，若当前处于知识库视图，自动跳转回对话视图（新对话是对话行为，不应停留在知识库页面）。
- 用户可以在对话内容区域中输入问题，模型回复以流式方式逐步显示。
- 生成过程中，回答上方显示「思考」块（浅色小字，默认展开），实时打印助手的执行过程，包括：工作环节与耗时（如「理解问题」「检索知识库」「校验回答依据」）、各环节的决策输出（意图判定、编排决策、证据评估、依据校验判定等）、检索运行细节（查询数、命中数、重排情况）、检索策略列表（本次使用的全部检索查询：原始问题、改写、子问题拆分、术语扩展；重新规划时该列表更新），以及回答重写/兜底等流转过程说明。
- 「思考」块标题可点击展开或收起；回答输出完成后思考块自动收起为一行摘要（如「已完成思考 · 18.5s」），点击可重新展开查看完整过程；发起新提问时重新开始记录。
- 回答出错时思考块保留显示（可查看出错前执行到哪一步），错误提示单独显示。
- 思考内容仅在当前浏览期间保留：刷新页面或重新打开会话后，历史消息不显示思考块。
- 一般性对话（问候、概念解释、系统功能说明类问题）同样显示思考块，只是没有检索相关条目。
- 一般性对话（问候、概念解释、系统功能说明类问题）不经知识库检索直接回答，不显示检索策略列表；法律事实型问题默认检索知识库。
- 请求网络搜索或插件能力时，助手会明确说明该功能尚未开通，不编造外部结果。
- 回答在完成后会经过自动校验；校验未通过时回答会自动修正或补充检索后重新生成，生成中的内容会被清空重写，用户无需手动操作。
- 显示历史对话，可以删除对话。
- 侧边栏历史对话按创建时间从上到下排列：最早创建的在最上面，新创建的会话追加到最下面。
- 对话内容按发生时间从上到下正序展示：提问在上、对应回答在下。

## 4. 参考文档（回答依据展示）
- 当回答基于知识库检索（RAG）且检索有命中时，回答完成后下方显示「参考文档」按钮；点开后按序号展示参考的文档名称与对应命中内容（按相关性重排，最多 10 条），刷新或重新打开会话后仍可查看。
- 检索到部分相关证据时，回答会基于已有证据谨慎作答并正常展示参考文档；完全无命中时回答明确声明"知识库中暂无相关依据，建议咨询专业律师"，不显示「参考文档」按钮。
- 当回答未使用知识库检索（直接回答）或检索无命中时，不显示「参考文档」按钮。

## 5. 视觉与交互风格
- 界面设计风格与功能类似 Codex 网页版：审美高（接近苹果与 Claude 的设计语言），交互简单。

| D1 | 检索策略全量展示：检索计划携带全部查询（原始/改写/子问题/术语扩展，去重后 ≤8 条），前端文案「检索策略（N 条查询）」 |
| D2 | 直接回答路径：一般性问题（问候/概念解释/系统说明）跳过检索直接回答，不显示检索策略、不声明"暂无依据"；法律事实型问题默认走知识库检索 |

| D11 | 闲聊/直接回答路径同样展示思考块（无检索条目，交互全站一致） |
| D12 | 回答出错时保留思考块（可查看出错前执行到哪一步），错误提示单独显示 |
